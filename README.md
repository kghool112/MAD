# الوسطى ستور — ثيم سلة

مشروع ثيم عربي لمتجر «الوسطى ستور» للأجهزة والإكسسوارات. هذه نقطة تنظيم أولية؛ ملفات الثيم الفعلية يجب إنشاؤها من قالب سلة الرسمي عبر Salla CLI حتى تبقى متوافقة مع أدوات سلة.

## الهوية والهدف

- واجهة عربية باتجاه RTL.
- ألوان أساسية: الأسود والأبيض، مع أخضر ليموني `#c8f03c`.
- أقسام المتجر: الهواتف، الأجهزة اللوحية، الحواسيب، الإكسسوارات، وخدمات الاتصالات.
- الهدف الأول: إنشاء الثيم بالقالب الرسمي ثم تشغيل معاينة محلية قبل تعديل التصميم.

## إنشاء ملفات الثيم

على Windows، بعد تثبيت Node.js وGit وSalla CLI وتسجيل الدخول لحساب الشركاء:

1. شغّل `salla theme doctor` للتأكد من جاهزية الأدوات.
2. شغّل `salla theme create` واتبع الخيارات الظاهرة لإنشاء ثيم React باسم «الوسطى ستور».
3. إذا طلب CLI اختيار مستودع، اختر المستودع الذي سيُنشأ أو يُربط بالثيم. لا ترفع ملفات أسرار أو ملفات `.env`.
4. ادخل مجلد الثيم الذي أنشأه CLI وشغّل `salla theme preview` لمعاينته.

> قد تختلف الأسئلة التي يعرضها CLI حسب نسخته. اتبع الخيارات التي تظهر في جهازك، ولا تنشر الثيم قبل التأكد من المعاينة.

## هيكل العمل بعد إنشاء القالب

ينشئ Salla CLI ملفات المشروع وإعداداته المناسبة. سنضيف التخصيص تدريجيًا داخل هذا الهيكل، مثل:

- مكونات الواجهة والأقسام.
- التنسيقات والألوان.
- النصوص العربية وبيانات الترجمة.
- الصور والوسائط التي يملكها المتجر.

## الأمان

- لا ترفع كلمات المرور أو رموز GitHub أو مفاتيح API.
- ملف `.env` محلي وسري؛ لا تشاركه ولا ترفعه.
- أبقِ التغييرات صغيرة، وعاينها قبل اعتمادها.

## الحالة الحالية

المستودع يحتوي على وثيقة المشروع وملف تجاهل أساسي فقط. لم تُنشأ ملفات الثيم بعد؛ الخطوة التالية هي إنشاء القالب الرسمي باستخدام Salla CLI على جهاز Windows.
